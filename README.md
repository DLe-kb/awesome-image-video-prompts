## 如何使用

1. 打开[交互画廊](https://dle-kb.github.io/awesome-image-video-prompts/)，按生图或生视频筛选，也可以搜索题材和用途。
2. 在原创案例页复制完整提示词，替换主题、产品和画幅等变量；视频模板根据所用模型补充参考素材与参数。
3. 在来源索引中打开原作者页面，查阅原作品与适用条件。
