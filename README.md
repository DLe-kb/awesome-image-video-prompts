## Quick Start

1. Find a direction in the gallery below, the [full catalog](docs/CATALOG.md), or the [online gallery](https://dingle-kb.github.io/awesome-image-video-prompts/).
2. Open its `style.json` and provide the complete file to an image or video generation model. For plain text, open its Copy Prompt page instead.
3. Change the subject, input materials, or template variables while keeping the composition, camera, and style constraints you need.

```text
styles/<slug>/
  style.json       Full prompt, category, attribution, and relationships
  preview.jpg      Image preview or video poster, when available
  sample.mp4       Video clip, when available
```

Some image previews use `preview.webp`; linked versions reference their related case's media. Each folder has one machine-readable content file. Copy pages and gallery data are generated from these files. Identical source and linked prompts share one file; distinct versions have their own linked folders.
