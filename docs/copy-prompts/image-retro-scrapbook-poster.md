```text
标题、简短副标题、底部说明和小型装饰围绕图二主题展开，文案与配色根据图二内容对应调整。使用粗体复古展示字、少量手写感辅助字、相关的小图标和纸张印刷纹理。文字清晰可读，不遮挡主体，整体层级明确、留白合理。

如果已提供具体文案，原样使用；否则只生成与图二主题一致的简短描述，不编造功效、价格或商业承诺。不出现图一的品牌、标志或水印，不输出参考图对比、教程字幕或分屏。
```
